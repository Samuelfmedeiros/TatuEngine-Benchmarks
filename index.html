02 / Honesty

The in-distribution number was too kind.

A paired held-out test — same checkpoint, same corpus, in training versus out — changed the reading entirely.

⚠ Correction, not a footnote

The in-distribution gain was first read as specialization. It was memorization: on clean held-out documents, loss rises 30.5% on legal PT-BR and 41.2% on wiki PT (same checkpoint, same tokenizer, same sequence length). There is no domain skill here — there is recall of documents already in the training tensor.

03 / Boundary

What you can and cannot verify.

Fully reproducible

Every loss and perplexity figure: corpus sizes, token counts and steps are in the logs. The arithmetic is checkable.

Independently checkable

Roundtrip byte-identity and compression ratios — rerun the same tools on the same public corpora and compare.

Not published

Engine source, CUDA kernels, weight checkpoints and corpus contents. This repository is proof and portfolio, not a distribution.
